# Rice Mill Manager

Paddy purchase, milling, stock, sales, accounts, GST & Tally export, govt. custom milling (CMR) and Excel import for rice mills.

**Open the app:** https://antonyraj09.github.io/RICE_MILL/

- Works on iPhone, Android and computers. Add it to the Home Screen to use it like an app.
- After the first open it works without internet. Data is saved on each device.
- To sync several devices, run the sync server from the full package and enter its address in Settings → Sync & devices.
